Comprehensive Google Workspace control: Gmail, Calendar, Docs, Sheets, Slides, Chat, Forms, Tasks, Search, Drive.

Security Review:

# ⚠️ High-privilege access:
- OAuth with broad scopes
- Read/write access to all G Suite data
- Email sending capabilities
- File deletion permissions

Features:

  • Full Gmail control (read/send/delete)
  • Calendar CRUD operations
  • Document editing (Docs/Sheets/Slides)
  • Drive file management
  • Tasks and Forms integration

Installation:

pip install google-workspace-mcp

Risk Assessment: ⚠️ REVIEW - HIGH PRIVILEGES

  • Requires OAuth with extensive scopes
  • Can read all emails and documents
  • Potential for data exfiltration if compromised
  • Rate limiting needed

Recommendation: Use with least-privilege OAuth scopes. Audit all operations. Consider read-only mode for exploratory use. Production use requires thorough vetting.
